# AI PM Assistant Implementation Plan

**Goal:** 单人需求分析工作台，本地与持久化磁盘服务器共用源代码。
**Architecture:** Next.js App Router；Node SQLite；服务端 DeepSeek adapter；口令与签名会话。
**Tech Stack:** Next.js 16, React 19, TypeScript, Node >=24.22.1。
**Spec:** 用户已批准本对话中的第一版设计；该批准优先，不再增加确认环节。

## Global Constraints

- 不创建外部仓库或发布。交付 ZIP 与中文说明。
- 密钥仅来自服务端环境；演示绝不替代真实失败。
- 数据跨项目隔离，生成保存输入及背景快照；编辑产生新版本。
- 运行只展示实际阶段；事实检查仅为引用和结构检查。

## Review Focus

- 无口令的生产环境拒绝服务；跨站写入拒绝。
- 不存在项目和跨项目文档引用不得读写。
- 模型空白、截断、无效结构、限流不得保存为成功。
- 取消和超时不生成成功文档；并发重复提交被拒绝。
- 恢复备份校验全部内容后事务性插入，不覆盖现有数据。
