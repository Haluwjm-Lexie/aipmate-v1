# V2.1 变更与验证（2026-11-05）

## 按用户反馈修复

- 个人版免密码；session为兼容旧前端保留，但不再校验口令。默认127.0.0.1:3020。同源写入检查、限流和服务端密钥保留。
- PMATE字标、紧凑页头和白底绿色布局；去掉重复品牌说明、个人页脚、滚动条（保留原生滚动）。
- 五入口对应独立项目/任务草稿键；结果与版本按类型筛选；失败不显示旧结果冒充成功。旧无类型文档归入需求分析；智能识别可看全部类型。
- 共用项目背景折叠；项目阶段标签显式标注“项目阶段”。任务输入和结果标题、提示随入口变化。
- 任务删除API限定项目和非运行状态，只删除runs，不删除documents。
- 阶段单选，兼容旧自定义阶段。项目名称必填100字；其他文本选填6000字。
- 新增资料库：标题100字、正文50000字、项目20份/20万字。Markdown/TXT导入是浏览器读取纯文本，不执行文件。文本关键词匹配，1600字片段/1200字步长，最多5片段。相关资料进入原八节点上下文与证据清单，来源ID和引文真实验证；未命中不伪造。
- 无新增SQL表或迁移，knowledge为原项目JSON新增属性。备份与恢复保留资料，导入仍作为副本。
- DeepSeek连接状态、资料数量与联网搜索能力分开。尚未实现联网搜索，不把模型已连接当搜索已连接。老师四类专业System/User没有改写。

## 已验证

- 31项自动化测试全部通过；包含原专业工作流与新任务筛选、无密码同源限制、资料隔离/引用/备份恢复、删除任务保留文档。
- Next.js生产构建与TypeScript通过。
- 在隔离临时DATA_DIR启动生产服务，实际HTTP验证首页200、免密码session、创建项目、资料增查删及搜索能力状态。
- 日志见docs/evidence/v2.1-*。
