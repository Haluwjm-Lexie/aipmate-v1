## 自动化覆盖的行为

| 领域 | 覆盖内容 |
|---|---|
| 项目 | 创建两项目、更新背景、删除、项目间文档隔离 |
| 文档 | 生成保存、编辑追加版本、保留原文、删除单版本 |
| 备份 | 导出、事务性导入副本、拒绝异常格式、保留追问回答、模型与用量 |
| 认证 | 无会话拒绝、登录、签名篡改、过期、错误来源拒绝、生产无口令拒绝 |
| 模型结果 | 合法结构、追问、空白结果、错误 JSON 结构、截断、无密钥、无效密钥 |
| 任务 | 重复提交拒绝、运行时拒绝删除项目、取消任务、失败不生成文档 |
| 敏感配置 | 备份不包含环境中的测试 API 密钥 |

模型成功、追问、截断、认证失败与取消测试使用受控上游响应，并非真实 DeepSeek 调用。认证和 SQLite 读写走真实应用逻辑，不是模拟保存。

## 首次运行后请检查

- 登录并打开模拟项目，确认演示标识。
- 新建两个项目，切换并刷新，确认背景、任务和文档不串。
- 填写真实模型配置后测试连接，再提交一个小任务。
- 检查正文中的功能编号、异常与验收标准是否一致。
- 编辑并保存新版本，确认旧版仍可读取；编辑中不应能直接启动新分析。
- 导出备份后导入为副本，检查追问回答和项目快照。
- 在手机浏览器确认侧栏展开、输入与表格横向滚动。

## 已知边界

- 只开放需求分析，无自动联网、文件上传、多人协作或自动原型。
- 单实例 SQLite，必须使用持久化磁盘；本地实例和云实例不会自动同步。
- 导入最多 2 MB、100 项目、每项目 300 文档。导出不限制大小；超过导入上限的备份需通过停机复制 data 目录迁移，界面暂未提供分拆工具。
- AI 输出需人工评审。结构与引用完整性检查不代表独立核实全部事实。
